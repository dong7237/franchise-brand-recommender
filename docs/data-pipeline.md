# 데이터 수집과 모델 입력 구성

## 구현 범위와 AI 활용
수집할 데이터와 활용 목적을 전달하고 Codex를 활용해 API 수집·SQL 적재 환경을 구성했습니다. 이 문서는 SQL 뷰의 용도와 모델 입력 가공 흐름을 설명하며, 실행 코드는 학습·추천 모듈을 제공합니다.

## 원천과 가공
공정거래위원회 가맹사업 정보공개서의 매출·가맹점 수·초기 부담금·업종 정보를 사용했습니다. 비공개된 매출·부담금 일부는 가상 값으로 보완했습니다. 브랜드 CSV에는 비용 관련 출처 URL 또는 `LLM 추정값` 표시가 포함되어 있습니다. 모든 수치의 원자료/가상 값 구분이 완전한 것은 아니므로 공개 브랜드 CSV를 혼합 데이터로 표시하며, 기존 출처 열을 보존했습니다.

`analysis.ipynb`에서 확인한 조회 경로:

| 뷰 | 용도 | 모델 입력 가공 |
|---|---|---|
| v_agent_sales | 지역별 매출·점포 수 | 서울 지역, 점포 수 0 제외; 3.3㎡당 매출과 점포 수 추출 |
| v_agent_startup_costs | 창업비용 항목 | INITIAL_FRANCHISE_FEE의 총계 추출 |
| v_agent_brand_overview | 브랜드 개요 | 브랜드명·중분류 업종 연결 |

브랜드명으로 비용·매출·점포 수·업종을 결합합니다. 매출·점포 수는 높은 값, 비용은 낮은 값에 높은 구간 점수를 부여하고 세 구간 코드를 결합한 `cat`을 만듭니다. `cat`은 수치 특성을 요약한 브랜드 유형 코드입니다.

비용 CSV는 천원, 고객 자금은 만원 단위이므로 모델의 비용 특성 생성 시 10으로 나눠 단위를 맞춥니다. `average_sales_per_3_3sqm`의 단위는 **3.3㎡당 평균 매출액**입니다.

## 공개 샘플
- 가상 고객: 기존 1만 명에서 매칭 브랜드별 최대 5명씩 추출한 실행 예시입니다.
- 매칭 라벨: 기존 LLM 매칭 및 업종 정렬 과정에서 관리된 기준 라벨입니다.
- 브랜드: 442행, 고유 439개. 기존 코드와 동일하게 브랜드명 중복 시 마지막 행을 사용합니다.
- 샘플 데이터는 학습·추천 실행 예시로, 전체 실험의 결과는 `reports/original/`에 별도로 제공합니다.
