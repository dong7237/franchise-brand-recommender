# 평가 지표 읽는 법

## 평가 기준
기존 LLM 브랜드 매칭 결과를 기준 라벨로 사용해, 모델의 첫 추천 일치율과 최종 후보 내 포함률을 평가했습니다. 전체 439개 브랜드 중 기준 라벨에 등장하는 브랜드는 69개입니다.

원본의 `relabel` 코드는 업종이 맞지 않는 라벨을 추천 결과로 교체합니다. 라벨 수정과 학습·평가의 전체 실행 순서는 추가 확인 대상이며, 현재 수치는 저장된 기준 라벨에 대한 일치 결과로 해석합니다.

## 결과 파일과 분모
| 결과 | 분모 | 첫 추천 예산 적합률 |
|---|---:|---:|
| evaluation_preference_fixed.json | 평가 고객 2,000명 | 84.45% |
| rebuild_validation.json의 full_output_validation | 전체 가상 고객 10,000명 | 83.66% |

README에는 최종 추천 조건을 적용한 평가 고객 2,000명의 결과를 사용합니다. 첫 추천 라벨 일치율은 57.55%, 최종 후보의 라벨 포함률은 70.10%입니다. 전체 고객 결과는 별도 분모로 구분해 기록했습니다.

## 공개 패키지 검증
- 원본 추천 CSV에서 평가 고객 수, 첫 후보 라벨 일치율, 예산 적합률을 재계산해 저장 JSON과 대조했습니다.
- 가상 고객 345명 샘플로 학습을 실행하고, 예시 고객 3명의 추천 결과를 확인했습니다.
- 전체 실험 지표와 샘플 실행 결과는 각각 실험 기록과 실행 예시로 구분합니다.
